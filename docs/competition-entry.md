## Project description

Midnight Zombies is a creepy-cute, one-tap racing game built with OpenAI. Four stitched-together zombie racers dash through a moonlit town to reach the Monster Bash before sunrise. Fast, correct taps move you forward; wrong taps make your zombie stumble apart. Earn candy boosts and mischievous items, and race with an original ghost sidekick: Mach the falcon, Slink the serpent, Ember the wolf, or Misty the bat.

Play solo against personality-driven rivals or share a four-letter room code with friends for a live multiplayer race on their own phones. The server keeps challenges, positions, items, and the winner synchronized. Solo play starts gently and progresses through four unlockable levels: Spiral-Hill Graveyard, Crooked Pumpkin Patch, Leaning Haunted House, and Monster Bash Bell Tower. Later levels introduce more challenge types, faster timers, and tougher rivals. Earn medals, coins, and cosmetic rewards saved in your browser.

The original art pairs detailed handmade zombie puppets with translucent, flowing ghost creatures, inspired by the creator's own Mach video. Glowing blue moonlight and warm amber lanterns light a crooked Halloween village. No login or installation is required.

## Demo flow

1. Open the game and select a ghost team.
2. Start Level 1; demonstrate a correct tap, an item, and the finish screen.
3. Show the unlocked next level and retained medal.
4. Create a room, join from a second browser or phone, mark ready, and start a shared race.

## Hosting notes for a demo

The Render free instance can take about a minute to wake after inactivity. Rooms are in memory and are lost on a server restart; personal rewards and level progress remain in that browser. Open the game before demonstrating it. Global weekly team standings are not implemented; the game shows personal team points.
